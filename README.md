# PIXELSCAPE JSON-FMT — Formatter & Validator

A retro terminal-style developer utility for formatting, minifying, validating, and exploring JSON structures.

## Features

- **Format & Minify**: Prettify messy JSON with custom indentation (2-space, 4-space, tabs) or minify for compact payloads.
- **Syntax Validation & Error Highlighting**: Real-time parser with line and column error indicators.
- **Collapsible Tree View**: Interactive tree inspector with search, node expansion, and path copying.
- **Retro Terminal Aesthetic**: Inspired by amber CRT screens and vintage CLI tools.
- **Offline & Private**: Client-side parsing ensures API keys, tokens, and sensitive JSON payloads remain on your device.

## Getting Started

Open `index.html` in any modern web browser or try it on https://jameop1.github.io/pixelscape-json-formatter/
